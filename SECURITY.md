# Security policy

## Supported versions

Only the latest release of this fork receives fixes. It supports Blender 5.3.

This is a fork of [Tissue](https://github.com/alessandro-zomparelli/tissue). If the problem is also in the official Tissue, please tell its author too, privately.

## Reporting a problem

If you find a security problem, for example something that could make Blender run unexpected code when you open a file, or a problem with the Install Numba button, **please don't open a public issue.**

Report it privately instead: go to the repository's **Security** tab and choose **Report a vulnerability** ([direct link](https://github.com/mttfntn/tissue-blender-5/security/advisories/new)).

Please describe the problem and how to reproduce it. You'll get a reply as soon as possible, and the fix will be released before the details are made public.
